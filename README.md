# MBSE Modeling Tool

A web-based tool for Model-Based Systems Engineering (MBSE) built with Python and Streamlit.

## What it does
- Supports 4 MBSE methodologies: OOSEM, V-Model, RFLP, and PPR
- Add nodes and connections to build system architecture models
- Visualises models as color-coded diagrams
- Export models as JSON, PDF, PNG, or SysML v2 text format

## Demo model included
`mbse_model.json` — a coffee machine modelled across all 4 methodologies (94 nodes, 100+ connections)

## How to run
1. Install dependencies: `pip install streamlit graphviz`
2. Run: `streamlit run final.py`
